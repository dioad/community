This is the public place to ask questions, report problems and suggest ideas for
[Dioad connect](https://dioad.dev/connect/index.html) and
[Dioad edgemail](https://dioad.dev/edgemail/index.html).

The code for both products is not published here. This repository exists for
issues and discussion only.

## Status

Dioad is a small independent project. connect is in beta and edgemail is in
alpha. Both are free during the beta, and you use them at your own risk.

- There is no support team and no uptime guarantee.
- We read every issue, but we can't promise a reply time. Replies are best effort.
- The service runs from a single region (London).
- Features, limits and plans may change. We'll say so before anything changes
  that affects you.

## Where to go

| You want to | Go to |
|---|---|
| Report a bug in connect | [New issue](../../issues/new?template=bug_connect.yml) |
| Report a bug or delivery problem in edgemail | [New issue](../../issues/new?template=bug_edgemail.yml) |
| Suggest something | [New issue](../../issues/new?template=feature_request.yml) |
| Report a security problem | [Security policy](SECURITY.md). Don't open a public issue. |
| Get set up | [connect getting started](https://connect.dioad.dev) |
| Read the docs | [connect documentation](https://dioad.github.io/connect/) |

Please search existing issues first. If your problem is already reported, add
what you know to that issue.

## Before you post

Never paste passwords, tokens, private keys, the contents of your `persist`
volume or the text of private email. Redact them. We will never ask for them.
